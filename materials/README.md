# Lecture materials

Put original PowerPoints, PDFs, and notes here, one folder per class:

- `history-physical/` — Medical History & Physical Exam
- `physiology/` — Medical Physiology
- `anatomy/` — Anatomy

Naming them with the lecture number keeps sections in order, e.g.
`03 - Cardiac Cycle.pptx`. Each file becomes one section of flashcards in
`data/decks/`.
